# 全局下拉控制中心

## 概要

在 ESP32/LVGL 界面中增加类似手机的全局下拉控制中心。它可以从桌面、App 和设置子页面顶部拉出，并提供 Wi-Fi 设置入口、屏幕方向锁、亮度和音量控制。

现有底部上滑导航只识别底部 10 px，新手势限定从顶部边缘开始，因此可以共存。通过统一的手势状态机保证同一次触摸只交给一个系统手势。

## 实现改动

- 新增独立的 `control_center` UI 模块，挂载到 LVGL 顶层：
  - 220 px 高深色面板，下方保留背景提示区域和关闭手势。
  - 顶部显示时间、Wi-Fi、SSID 和电量。
  - Wi-Fi 快捷按钮直接进入现有 Wi-Fi 设置子页，不负责开关无线。
  - “Rotation lock”按钮启用时调用 `hal_autorotate_enable(false)`，锁定当前方向；关闭时恢复自动旋转。
  - 亮度滑杆使用 `hal_get/set_brightness()`，范围保持现有的 8%–100%。
  - 音量滑杆使用 `volume_service_get/set()`，范围 0%–100%，继续沿用延迟写入 NVS 的机制。
  - 使用现有 Wi-Fi 位图和 LVGL 字体符号，不新增图片资源。

- 实现跟手下拉：
  - 触摸必须从顶部 12 px 内开始。
  - 移动超过 8 px 后判断方向，只有纵向向下手势接管控制中心。
  - 面板随手指位置移动；松手时根据可见距离和末段速度吸附展开或收回。
  - 展开后可从底部把手向上滑或点击面板外区域关闭。
  - 控制中心正在展开、显示或关闭时暂停底部导航识别，避免触发返回桌面或最近任务。
  - 水平滑动和非顶部起始的纵向滚动继续交给桌面分页、Settings 列表及 App 控件。

- 接入现有导航和设置：
  - 为控制中心提供打开 Wi-Fi 设置的系统回调。
  - 给 Settings 增加幂等的 Wi-Fi 子页入口；已经位于 Wi-Fi 页面时只关闭控制中心，不重复创建页面。
  - 从其他 App 打开 Wi-Fi 设置时按现有生命周期切换到 Settings。
  - Settings 中的自动旋转开关和亮度显示定期读取 HAL 状态，确保从控制中心修改后界面同步。
  - 控制中心状态栏每 500 ms 更新一次时间、网络和电池状态。

## 接口变化

- 新增控制中心初始化、轮询、显示状态和关闭接口，供 `ui_init()`、`ui_tick()` 与系统导航调用。
- Settings 暴露一个受保护的 Wi-Fi 子页打开接口。
- 不改变 `AppDefinition` 和 `AppContext` 的公共结构，也不改变现有 App 注册方式。

## 验证

- 运行 `pio run`，确认固件编译和内存占用正常。
- 在桌面四个分页、普通 App、Settings 滚动页和 Wi-Fi 子页验证顶部下拉。
- 验证桌面左右滑、Settings 纵向滚动、亮度横向拖动不被错误拦截。
- 验证底部短上滑返回、停留打开最近任务、最近任务上滑清理仍正常。
- 验证方向锁立即固定当前方向，解除后自动旋转恢复，Settings 开关同步。
- 验证亮度和音量滑杆实时生效，音量仍能持久化，实体音量键仍可使用。
- 验证 Wi-Fi 按钮能从任意页面进入 Wi-Fi 子页，重复点击不会叠加页面。
- 验证控制中心与音量提示、调试悬浮层没有失控遮挡或触摸穿透。

## 默认约定

- 控制中心文字沿用项目现有英文界面。
- 方向锁和亮度保持当前工程行为，不新增重启持久化；音量继续持久化。
- 不实现熄屏、密码锁屏或触摸禁用。
- 当前基线 `pio run` 可成功完成；环境会输出 Python externally-managed 警告，但不影响现有固件构建成功。
